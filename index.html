Put this planner on your site

For trlibrary.com editors and partners. Paste into a Drupal Code (embed) block or any web page. The planner draws straight into the page (no iframe) and styles only itself.

<div data-trnp-planner></div>
<script src="https://trnp-planner.labs.trlibrary.com/embed.js" async></script>

Optional settings on the div:

AttributeWhat it doesExample
data-fromStarting point picked on load: library, south, north or i94data-from="i94"
data-timePark minutes picked on load: 90, 120, 180, 240, 360 or 540 (a Library visit, when included, comes on top)data-time="240"
data-titleoff hides the planner's own "Got two hours?" heading when the page already has onedata-title="off"
data-sticky-topPixels to keep the map clear of a fixed site header while scrollingdata-sticky-top="110"

Links work too: trnp-planner.labs.trlibrary.com/?from=i94&t=120 opens the two-hour plan for I-94 travelers. The same parameters work on any page that embeds the planner, and the planner keeps them in the address bar so Copy link shares the exact plan.
